=== سئویار ===
Requires at least: 6.2
Tested up to: 6.8
Requires PHP: 7.4
Stable tag: 1.0.0
License: GPLv2 or later

اصلاح‌هایی را که در سئویار تأیید کرده‌اید روی سایت وردپرسی اعمال می‌کند.

== Description ==

* عنوان صفحه و توضیحات متا را در جایی می‌نویسد که افزونه‌ی سئوی شما می‌خواند (Yoast SEO، Rank Math یا خود سئویار).
* متن جایگزین تصاویر را در کتابخانه‌ی رسانه و در محتوای صفحه تنظیم می‌کند.
* تصاویر بدون متن جایگزین را برای بررسی به سئویار می‌فرستد.
* هیچ تغییری بدون تأیید شما انجام نمی‌شود و هر تغییر از داخل سئویار قابل بازگشت است.

== Installation ==

1. افزونه را بارگذاری و فعال کنید.
2. در سئویار، از صفحه‌ی «کلیدهای API» یک کلید با دسترسی `read,write` بسازید.
3. در وردپرس به «تنظیمات > سئویار» بروید و نشانی سئویار، شناسه‌ی پروژه و کلید را وارد کنید.
4. «همگام‌سازی الان» را بزنید.

حذف افزونه فقط تنظیمات آن را پاک می‌کند و تغییرهای اعمال‌شده روی سایت می‌مانند.
