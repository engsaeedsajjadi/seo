## راهنمای استفاده

### در کد

```typescript
// ✅ درست - استفاده از واژه‌نامه
t('common.dashboard') // "داشبورد"
t('audit.criticalIssues') // "مشکلات بحرانی"

// ❌ غلط - ترجمه مستقیم بدون واژه‌نامه
"داشبورد" // سخت‌کد شده
```

### در مستندات

همیشه از ترجمه‌های استاندارد این واژه‌نامه استفاده کنید.

### افزودن واژه جدید

1. واژه را به این فایل اضافه کنید
2. ترجمه را به `src/i18n/fa/common.ts` یا ماژول مربوطه اضافه کنید
3. در PR توضیح دهید
